       AllowCraftSpheres, user 2026-10-19). One recipe per type, CraftMinidoracatPackThrow<empty item> (Core t.recipe);
       OnTest and OnAddToMenu both name the global MinidoracatPackThrow_craft<id> (lua/shared/MinidoracatPackThrow/
       Recipes.lua: OnTest resolves dotted names, OnAddToMenu only globals).
       - module Base: short recipe names resolve in Base only (family pitfalls.md "CraftRecipe"); items keep their
         module and are written as full types. NeedToBeLearn stays false: no magazine to keep.
       - Laid out like the vanilla electrical recipes (recipes_radio.txt CraftMakeshiftRadio, recipes_electrical.txt
         MakeImprovisedFlashlight): a work surface (AnySurfaceCraft), MakingElectrical, Electrical category.
       - The seven capsules take the same parts (only the looks differ): a car battery's power, any charge (drainable:
         mode:destroy with ItemCount, else empty ones are swept up with it), a shell and the electronics.
       - Pal Spheres climb like Palworld's: the Pal Sphere from parts, each higher tier from an empty one of the tier
         below plus parts; a higher Electrical level each tier.
       Names: Translate/<language>/Recipes.json, keyed by recipe name (Translator.getRecipeName). */

    craftRecipe CraftMinidoracatPackThrowCapsuleCartoon
    {
        timedAction = MakingElectrical,
        time = 200,
        SkillRequired = Electricity:4;Mechanics:2,
        OnTest = MinidoracatPackThrow_craftCartoon,
        OnAddToMenu = MinidoracatPackThrow_craftCartoon,
        Tags = AnySurfaceCraft,
        category = Electrical,
        xpAward = Electricity:20;Mechanics:10,
        inputs
        {
            item 1 tags[base:screwdriver] mode:keep flags[NoBrokenItems;Prop1],
            item 1 tags[base:pliers] mode:keep flags[MayDegradeLight],
            item 1 tags[base:carbattery] mode:destroy flags[ItemCount],
            item 1 [Base.SmallSheetMetal],
            item 4 [Base.ElectronicsScrap],
            item 1 [Base.Amplifier] flags[NoBrokenItems],
            item 2 [Base.ElectricWire],
            item 2 [Base.Screws],
        }
        outputs
        {
            item 1 MinidoracatPackThrow.CapsuleCartoon,
        }
    }
